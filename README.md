## ✨ Sobre o projeto

Este portfólio foi desenvolvido como uma aplicação web para centralizar minha apresentação profissional e meus principais projetos.

Além de apresentar informações sobre minha experiência e habilidades, o projeto utiliza animações e elementos interativos para criar uma experiência mais dinâmica e personalizada.

Entre os destaques estão:

* 🎨 Interface moderna e responsiva
* ✨ Animações e transições utilizando Framer Motion
* 🧩 Componentização com React
* 📱 Adaptação para dispositivos móveis
* 💼 Apresentação de projetos profissionais e acadêmicos
* 🛠️ Seção de tecnologias e habilidades
* 📄 Download do currículo
* 💬 Contato direto via WhatsApp
* 🌐 Navegação entre diferentes seções do portfólio
* 🪐 Avatar interativo com tecnologias orbitando ao redor

### 💼 Projetos

Seção dedicada aos principais projetos desenvolvidos, incluindo:

## 💻 Como executar o projeto

### Pré-requisitos

Antes de começar, você precisa ter instalado:

* Node.js
* npm
* Git

### Clone o repositório

```bash
git clone https://github.com/AMANDASALOMAO/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

### Instale as dependências

```bash
npm install
```

### Execute o projeto

```bash
npm start
```

O projeto será executado localmente através do servidor de desenvolvimento.

---

## 🏗️ Build

Para gerar a versão de produção:

```bash
npm run build
```

Os arquivos otimizados serão gerados na pasta:

```text
build/
```

---

## 🌐 Deploy

O projeto utiliza GitHub Pages para publicação.

Para realizar o deploy:

```bash
npm run deploy
```

O script de deploy gera a build de produção e publica o conteúdo através do pacote `gh-pages`.
